Горячие клавиши
  • I / O — In / Out; Shift+I / Shift+O — перейти к метке
  • ← → — шаг на кадр; Shift+← → — на секунду
  • Пробел / K — пауза; J / L — шаг на секунду; P — циклический предпросмотр In→Out
  • В тексте блока: Alt+↑/↓ — переместить; Alt+Enter — вставить фрагмент из плеера
  • Порядок блоков: перетащить за бейдж; клик по бейджу или свёрнутой строке — свернуть/развернуть
  • ПКМ в окне блока СИНХ/СТЕНД/ЛАЙФ/ШПИГ — добавить фрагмент из плеера, копировать/вставить
  • Новая строка: «хед», «лид», «зк», «синх», «стенд», «лайф», «шпи» + пробел — новый блок
  • ПКМ по пустому месту окна сценария — добавить блок нужного типа (в конец)
  • Ctrl+F — поиск; Ctrl+Z / Ctrl+Shift+Z — отменить/вернуть; Esc — закрыть поиск
