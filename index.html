Горячие клавиши
  • I / O — In / Out; Shift+I / Shift+O — перейти к метке
  • ← → — шаг на кадр; Shift+← → — на секунду
  • Пробел — пауза; P — циклический предпросмотр In→Out
  • В тексте блока: Alt+↑/↓ — переместить; Alt+Enter — вставить фрагмент из плеера
  • Новая строка: «хед», «лид», «зк», «синх», «стенд», «лайф», «шпи» + пробел — новый блок; клик по бейджу — сменить тип
  • Ctrl+F — поиск; Ctrl+Z / Ctrl+Shift+Z — отменить/вернуть; Esc — закрыть поиск
