МЕДИАЦЕНТР (Сюжет-Студия) — сценарии сюжетов с разметкой видео
==============================================================

ЗАПУСК
------
1. Двойной клик по «Запустить сервер.command» (один раз настроить: правый клик →
   Открыть, чтобы macOS разрешила запуск).
2. Сервер стартует, и браузер откроется сам: http://localhost:8765
3. Коллеги в той же сети открывают адрес вида http://192.168.x.x:8765 —
   он показывается в окне терминала при запуске.
   Внимание: сервер (server.py) без пароля — доступ к странице и к записи
   общего списка имён (names.json) есть у всех в локальной сети.

Рекомендуемый браузер: Chrome или Edge. В них же папка исходников запоминается:
после выбора кнопкой «📁 Исходники» в шапке сюжета кнопка ⟳ над списком файлов
открывает её заново без повторного выбора (браузер лишь подтвердит доступ одним
кликом). Файлы никуда не копируются; после перезагрузки страницы файл всё равно
нужно открыть из папки заново — так устроена защита браузера, список при этом
восстанавливается по ⟳. На других браузерах (и на Some SMB-томах при сбоях)
работает старый способ: выбор папки заново, имя прошлой подсказывается.

РАБОТА
------
1. Реквизиты сюжета — в шапке (под названием): REP / CAM / EDIT (ФИО),
    кнопка «📁 Исходники» (рядом — имя текущей папки) и ⚙ — настройки: FPS
    таймкодов и PACE (темп чтеца). ИД/время изменения и FPS — в статус-баре
    внизу окна. Списки ФИО запоминаются и подставляются автоматически.
   Кнопка «⚙» у поля — управление списками имён: переименование и удаление.
    «Общие» имена хранятся в names.json на сервере; список с версией (_v):
    одновременная правка двумя людьми не затирает чужие данные — второй увидит
    предупреждение и свежие имена подтянет автоматически при возврате на вкладку.
    «локальные» — только в браузере этого компьютера.
    Требования: сервер должен быть запущен через «Запустить сервер.command»
    (server.py) — тогда имена можно править из интерфейса (запись защищена от
    межсайтовых запросов).
2. Папка с видео (можно по сети /Volumes/...) — «📁 Исходники» в шапке
     сюжета (или ⟳ над списком файлов в Media Browser), включая
     подпапки. Список файлов появится справа; файл в сюжете запоминает путь
     внутри папки — он попадает в экспорт (колонка «путь» в CSV Fish Cutter
     и MOGRT), поэтому одноимённые файлы из разных подпапок не путаются.
3. Клик по файлу в списке — видео в плеере (двойной клик по самому видео —
   play/pause). Окно монитора оформлено как Source Monitor Premiere Pro:
   серые панели, таймкод и SVG-иконки в транспортере, синяя зона In–Out
   на ленте перемотки.
4. Разметка фрагмента:
   - I  — вход,  O — выход  (или кнопки; Shift+I / Shift+O — перейти к метке)
   - ← →  — шаг на кадр,  Shift+← → — на секунду
   - P — циклический предпросмотр фрагмента In→Out (кнопки нет, только клавиша)
   - J / K / L — шаг назад / play-pause / шаг вперёд на секунду
   - Пробел — пауза. Ручки In/Out на скраббере можно тянуть мышью.
  5. СЦЕНАРИЙ — строки формата «[ТИП] ТЕКСТ [ХРОНО]», как в новостной ленте:
      бейдж типа слева (потянуть за него — переставить блок; клик по бейджу
      или по свёрнутой строке — свернуть/развернуть), текст в середине,
     длительность справа. Типы — интернациональные коды-бейджи с пиктограммой
      (стиль Octopus, мягкие цветные пилюли): HEADLINE (заголовок, синий) · LEAD
      (подводка/отвод, зелёный) · VO (закадровый текст, жёлтый) · SOT (синхрон,
      красный) · STANDUP (фиолетовый) · LIFE (оранжевый) · SPIEGEL (кирпичный).
      У SOT и STANDUP над текстом — титровая пилюля на всю ширину блока:
      иконка-человек, ИМЯ ФАМИЛИЯ (капсом), разделитель, должность.
      При сворачивании блока имя (и должность, если есть) видны в первой строке.
      Расшифровки в SOT/STANDUP/LIFE/SPIEGEL пишутся курсивом (и в Word-экспорте).
      Создание: ПКМ по пустому месту окна сценария → выбор типа (блок добавится
      в конец), или триггер в новой строке + пробел:
     «хед»/«заголовок», «лид»/«подв», «зк»/«vo», «синх»/«sot», «стенд», «лайф»,
      «шпи» — и английские: head, lead/toss, vo, sot, standup, nat, spiegel. Enter — абзац внутри блока; Backspace в начале строки — склейка с
     предыдущим; Alt+↑/↓ — переместить; Ctrl+Z/Ctrl+Shift+Z (и Cmd) — отменить/
      вернуть; Ctrl+F — поиск. Клик по бейджу сворачивает строку (или клик по
      свёрнутой), «All» — все разом.
      ПКМ внутри окна SOT/STANDUP/LIFE/SPIEGEL — своё меню: «🎞 Добавить фрагмент
      из плеера» (нужны открытый файл и метки I/O), «Копировать выделенное»,
      «Вставить» (по буферу; Ctrl+C/V работают всегда). В HEADLINE/LEAD/VO — как и
      раньше, нативное меню браузера.
     ХРОНО: у блоков с фрагментами — сумма таймкодов; у текстовых (HEADLINE, LEAD,
      VO) — оценка по длине текста (поле «PACE» в ⚙ настройках сюжета,
     по умолчанию 540), показывается с «~». Порядок строк = порядок экспорта.
 6. Фрагменты: отметьте In/Out в плеере и вставьте в блок правым кликом по окну
    блока («🎞 Добавить фрагмент из плеера») или Alt+Enter в тексте блока.
    «🎞 n ▾/▸» в строке блока — свернуть/
    развернуть список присоединённых фрагментов. Блок, где курсор, становится
    текущим (подпись «→ SOT 2» в транспортёре монитора) — синяя кнопка
    «Send →» в транспортёре шлёт помеченный фрагмент именно в него
    (в текстовые блоки — подсказка). У SOT несколько частей — отдельными
    строками. HEADLINE/LEAD/VO — только текст.
 7. Файлы сюжета — в верхнем меню «Проект»:
    - «➕ Создать…» — новый сюжет; «📂 Открыть…» / «💾 Сохранить…» —
      файл-черновик .json (включает блоки, реквизиты и fps).
     - «📤 Экспорт в Word» — текст сценария без файлов и таймкодов в настоящем
       .docx (файл открывается Word как обычный документ и нормально сохраняется;
       выключка слева по всему документу, расшифровки — курсивом).
       (В CSV и Word типы называются полным русским именем: «Закадровый текст»,
       «Синхрон», «Заголовок» — коды-бейджи (HEADLINE/VO/SOT…) это только
       интерфейс; импорт правок понимает и старые, и новые заголовки.)
     - «📥 Импорт из Word…» — вернуть правки редактора в сюжет: выбрать его файл
       (.doc/.docx/.txt). Старый бинарный .doc (Word 97–2003) не читается —
       попросите пересохранить в .docx. Если знакомых заголовков не найдено,
       подсказка покажет, какие строки файла не распознаны.
       Студия покажет обзор «было/стало» по каждому блоку;
      импортируются только тексты (для SOT/STANDUP — также имя/должность из
      заголовка «Синхрон 1. …» / «Стендап 1. …»). Блоки, которых нет в правке, можно удалить чекбоксом.
      Фрагменты и таймкоды в Word не хранятся — они не меняются.
      Редактору: правьте текст в вордовском документе и возвращайте тем же
      файлом (любой формат сохранения Word — .doc или .docx).
    - «🐟 В рыбособиратель» — CSV «;» для Fish Cutter: «Загрузить файл…» →
      выбрать CSV → «Проверить» → «Собрать рыбу». «📊 CSV для Excel «,»» —
      тот же файл с запятой.
    - «🎬 MOGRT титры» — CSV по всем титрам (сначала синхроны, затем стендапы
      с заполненным ФИО) для lower third шаблонов в Premiere: №; фамилия; имя;
      отчество; должность; вход (таймкод первого фрагмента — момент появления
      плашки); спикер целиком; файл входа; путь.
      ФИО в титрах пишите порядком «Имя Фамилия [Отчество]» — парсится по
      словам; колонка «спикер целиком» — подстраховка.
    Всё автосохраняется в браузере (до очистки данных сайта). Сюжеты лежат в
    IndexedDB (вместе с миниатюрами и памятью папки); при первом запуске новой
    версии данные автоматически переносятся из localStorage и освобожают его.
    Если браузер отказывает в сохранении (квота/приватный режим) — вверху
    появится красный баннер с диаграммой «что занимает место» и кнопками
    «Сохранить черновик сейчас» / «Снимок данных» (JSON для восстановления).
    После обновления файлов на сервере — обновите страницу с Cmd+Shift+R
    (или Ctrl+F5), чтобы браузер точно взял новые js/css.

ХРОНОМЕТРАЖ И ПЛАН
------------------
Низ строки «ИТОГО» показывает суммарный хронометраж сюжета. Рядом — кнопка
«план мм:сс ✎»: клик — задать хронометраж-цель этого сюжета (сохраняется с
ним). Если фактический ИТОГО превышает план, цифра становится красной.

СЮЖЕТЫ И КОМАНДНАЯ РАБОТА
-------------------------
Все сюжеты живут в этом браузере; переключение — меню «Проект» → «🎬 Сюжеты…»:
список сюжетов («✓» — текущий, справа — время изменения; внизу — «Дублировать
текущий» и «Удалить текущий»). Создание — «➕ Создать…», перенос между машинами —
«💾 Сохранить…» / «📂 Открыть…» (черновик .json).
Панель КОММЕНТАРИИ / ПРЕДЛОЖЕНИЯ / ЗАДАЧИ внизу: комментарий, оставленный, когда
курсор стоит в блоке сценария, привязывается к этому блоку (возле блока появляется
«💬n» — клик фильтрует комментарии блока; «→» у записи прыгает к нему).
Поиск в сюжете: Ctrl+F; перемещение блоков: Alt+↑/↓; фрагмент из монитора в блок:
ПКМ по окну блока или Alt+Enter.

Примечание: для дробных fps (29.97 / 59.94) таймкод считается как NDF с
30/60 кадрами в «секунде» таймкода — метки из монитора совпадают с Premiere.

Таймкоды считаются от начала файла (00:00:00:00 = первый кадр файла),
формат HH:MM:SS:FF NDF (без dropout-кадров).
