СЮЖЕТ-СТУДИЯ — сценарии сюжетов с разметкой видео
==================================================

ЗАПУСК
------
1. Двойной клик по «Запустить сервер.command» (один раз настроить: правый клик →
   Открыть, чтобы macOS разрешила запуск).
2. Сервер стартует, и браузер откроется сам: http://localhost:8765
3. Коллеги в той же сети открывают адрес вида http://192.168.x.x:8765 —
   он показывается в окне терминала при запуске.
   Внимание: сервер (server.py) без пароля — доступ к странице и к записи
   общего списка имён (names.json) есть у всех в локальной сети.

Рекомендуемый браузер: Chrome или Edge. Файлы никуда не копируются; папку с
видео нужно выбирать заново при каждом открытии страницы (браузер не хранит
доступ к файлам), имя прошлой папки подсказывается на вкладке «Авторы».

РАБОТА
------
1. Вкладка «Авторы» (кнопка в верхнем меню вместо Dashboard): FPS таймкодов,
    темп чтеца, ФИО корреспондента / оператора / монтажёра, папка исходников.
    Название сюжета — в шапке по-прежнему. Списки ФИО запоминаются и подставляются автоматически.
   Кнопка «⚙» у поля — управление списками имён: переименование и удаление.
   «Общие» имена хранятся в names.json на сервере (изменение видно всем после
   обновления страницы; перед записью сервер создаёт names.json.bak),
   «локальные» — только в браузере этого компьютера.
   Требования: сервер должен быть запущен через «Запустить сервер.command»
   (server.py) — тогда имена можно править из интерфейса.
2. Папка с видео (можно по сети /Volumes/...) — меню «Проект» →
    «📁 Папка исходников…» (или ⟳ над списком файлов в MEDIA), включая
    подпапки. Список файлов появится справа; имя файла с путём внутри папки
    попадает в экспорт.
3. Клик по файлу в списке — видео в плеере (двойной клик по самому видео —
   play/pause).
4. Разметка фрагмента:
   - I  — вход,  O — выход  (или кнопки; Shift+I / Shift+O — перейти к метке)
   - ← →  — шаг на кадр,  Shift+← → — на секунду
   - P (или кнопка «⟳ P») — циклический предпросмотр фрагмента In→Out
   - Пробел — пауза. Ручки In/Out на скраббере можно тянуть мышью.
 5. СЦЕНАРИЙ — строки формата «[TYPE] ТЕКСТ [DURATION]», как в новостной ленте:
    бейдж типа слева (клик по нему — сменить тип), текст в середине,
    длительность справа. Типы: HEADLINE (заголовок, синий) · LEAD (подводка/
    отвод, зелёный) · VO (закадровый текст, жёлтый) · SOT (синхрон, красный:
    спикер жирным капсом + «(СИНХРОН)», ниже реплика) · STANDUP (фиолетовый) ·
    LIFE (оранжевый) · SPIEGEL (кирпичный).
    Создание: кнопки «+ …» сверху или триггер в новой строке + пробел:
    «хед»/«заголовок», «лид»/«подв», «зк»/«vo», «синх»/«sot», «стенд», «лайф»,
    «шпи». Enter — абзац внутри блока; Backspace в начале строки — склейка с
    предыдущим; Alt+↑/↓ — переместить; Ctrl+Z/Ctrl+Shift+Z (и Cmd) — отменить/
    вернуть; Ctrl+F — поиск. ▾ сворачивает строку, «⤡ все» — все разом.
    DURATION: у блоков с фрагментами — сумма таймкодов; у текстовых (HEADLINE,
    LEAD, VO) — оценка по длине текста (поле «Темп чтеца, зн/мин» на вкладке
    «Авторы»,
    по умолчанию 540), показывается с «~». Порядок строк = порядок экспорта.
 6. Фрагменты: отметьте In/Out в плеере и вставьте в блок кнопкой «🎞 +» в конце
    строки блока (или Alt+Enter в тексте блока). «🎞 n ▾/▸» рядом — свернуть/
    развернуть список присоединённых фрагментов. Блок, где курсор, становится
    текущим (в панели плеера «→ SOT 2») — кнопка «В сценарий →» шлёт в
    него; цель можно выбрать и вручную. У SOT несколько частей — отдельными
    строками. HEADLINE/LEAD/VO — только текст.
 7. Файлы сюжета — в верхнем меню «Проект»:
    - «➕ Создать…» — новый сюжет; «📂 Открыть…» / «💾 Сохранить…» —
      файл-черновик .json (включает блоки, реквизиты и fps).
    - «📤 Экспорт в Word» — текст сценария без файлов и таймкодов.
      (В CSV и Word типы называются по-старому: «Закадровый текст/ЗК»,
      «Синхрон/СИНХ», «Заголовок» — английские бейджи это только интерфейс;
      импорт правок понимает и старые, и новые заголовки.)
    - «📥 Импорт из Word…» — вернуть правки редактора в сюжет: выбрать его файл
      (.doc/.docx/.txt). Студия покажет обзор «было/стало» по каждому блоку;
      импортируются только тексты (для синхрона — также спикер/должность из
      заголовка). Блоки, которых нет в правке, можно удалить чекбоксом.
      Фрагменты и таймкоды в Word не хранятся — они не меняются.
      Редактору: правьте текст в вордовском документе и возвращайте тем же
      файлом (любой формат сохранения Word — .doc или .docx).
    - «🐟 В рыбособиратель» — CSV «;» для Fish Cutter: «Загрузить файл…» →
      выбрать CSV → «Проверить» → «Собрать рыбу». «📊 CSV для Excel «,»» —
      тот же файл с запятой.
    - «🎬 MOGRT титры» — CSV по всем синхронам для заполнения lower third
      шаблонов в Premiere: №; фамилия; имя; отчество; должность; вход
      (таймкод первого фрагмента — момент появления плашки); спикер целиком.
      ФИО в блоке SOT пишите порядком «Имя Фамилия [Отчество]» — парсится
      по словам; колонка «спикер целиком» — подстраховка.
    Всё автосохраняется в браузере (до очистки данных сайта).

Таймкоды считаются от начала файла (00:00:00:00 = первый кадр файла),
формат HH:MM:SS:FF NDF (без dropout-кадров).
