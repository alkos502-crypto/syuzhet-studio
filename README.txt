СЮЖЕТ-СТУДИЯ — сценарии сюжетов с разметкой видео
==================================================

ЗАПУСК
------
1. Двойной клик по «Запустить сервер.command» (один раз настроить: правый клик →
   Открыть, чтобы macOS разрешила запуск).
2. Сервер стартует, и браузер откроется сам: http://localhost:8765
3. Коллеги в той же сети открывают адрес вида http://192.168.x.x:8765 —
   он показывается в окне терминала при запуске.
   Внимание: сервер (server.py) без пароля — доступ к странице и к записи
   общего списка имён (names.json) есть у всех в локальной сети.

Рекомендуемый браузер: Chrome или Edge. Файлы никуда не копируются; папку с
видео нужно выбирать заново при каждом открытии страницы (браузер не хранит
доступ к файлам), имя прошлой папки подсказывается в шапке.

РАБОТА
------
1. Шапка: название сюжета, FPS таймкодов, ФИО корреспондента / оператора /
   монтажёра. Списки ФИО запоминаются и подставляются автоматически.
   Кнопка «⚙» у поля — управление списками имён: переименование и удаление.
   «Общие» имена хранятся в names.json на сервере (изменение видно всем после
   обновления страницы; перед записью сервер создаёт names.json.bak),
   «локальные» — только в браузере этого компьютера.
   Требования: сервер должен быть запущен через «Запустить сервер.command»
   (server.py) — тогда имена можно править из интерфейса.
2. «Исходники» — папка с видео (можно по сети /Volumes/...), включая
   подпапки. Список файлов появится справа; имя файла с путём внутри папки
   попадает в экспорт.
3. Клик по файлу в списке — видео в плеере (двойной клик по самому видео —
   play/pause).
4. Разметка фрагмента:
   - I  — вход,  O — выход  (или кнопки; Shift+I / Shift+O — перейти к метке)
   - ← →  — шаг на кадр,  Shift+← → — на секунду
   - P (или кнопка «⟳ P») — циклический предпросмотр фрагмента In→Out
   - Пробел — пауза. Ручки In/Out на скраббере можно тянуть мышью.
 5. СЦЕНАРИЙ — как текст в Word: на белой «бумаге» блоки печатаются сверху
    вниз, метка типа (ЗК / СИНХ / СТЕНДАП / ЛАЙФ / ШПИГЕЛЬ / ПОДВОДКА) — на
    поле слева. Способы начать блок:
    - кнопки «+ …» сверху;
    - в новой строке набрать триггер и пробел/Enter: «зк», «синх», «стенд»,
      «лайф», «шпи», «подв» (на пустом блоке триггер меняет его тип).
    Enter — новый абзац внутри блока; Backspace в начале строки — склейка с
    предыдущим блоком; Alt+↑ / Alt+↓ — переместить блок. Порядок блоков =
    порядок сверху вниз = порядок экспорта.
    Отмена/вернуть — Ctrl+Z / Ctrl+Shift+Z (и Cmd на Mac). Поиск по тексту —
    Ctrl+F (Enter/Shift+Enter — переходы). ▾ сворачивает блок в строку,
    «⤡ все» — все разом. Всё сохраняется автоматически.
 6. Фрагменты: отметьте In/Out в плеере и вставьте в блок «🎞 Добавить
    фрагмент» (или Alt+Enter в тексте блока). Блок, где курсор, становится
    текущим (справа в панели плеера «→ ЗК 2») — кнопка «В сценарий →» шлёт в
    него; цель можно выбрать и вручную. У синхрона несколько частей —
    отдельными строками. Закадровый и подводка — только текст.
7. Экспорт:
   - «CSV для Fish Cutter» — разделитель столбцов на выбор рядом с кнопкой
     («;» — для панели, Tab/«,» — для Excel). Там: «Загрузить файл…» →
     выбрать CSV → «Проверить» → «Собрать рыбу».
   - «Word для редактора» — текст сценария без файлов и таймкодов.
   - «Правка из Word ↑» — вернуть правки редактора в сюжет: выбрать его файл
     (.doc/.docx/.txt). Студия покажет обзор «было/стало» по каждому блоку;
     импортируются только тексты (для синхрона — также спикер/должность из
     заголовка). Блоки, которых нет в правке, можно удалить чекбоксом.
     Фрагменты и таймкоды в Word не хранятся — они не меняются.
     Редактору: правьте текст в вордовском документе и возвращайте тем же
     файлом (любой формат сохранения Word — .doc или .docx).
   - «Черновик ↓/↑» — сохранить/продолжить работу (включает реквизиты и fps).
   Всё автосохраняется в браузере (до очистки данных сайта).

Таймкоды считаются от начала файла (00:00:00:00 = первый кадр файла),
формат HH:MM:SS:FF NDF (без dropout-кадров).
