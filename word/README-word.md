# Сюжет-Word — сценарии сюжетов в Microsoft Word + экспорт CSV для Fish Cutter

Шаблон Word с макросами: разметка видеоматериала (In/Out из монитора
«Сюжет-Студии»), сборка fish-CSV для плагина Premiere Fish Cutter и MOGRT-титров.
Формат заголовков блоков совместим с «Импорт из Word» медиацентра.

## Состав

    СюжетWord.dotm        — готовый шаблон с кодом (Word 16+, Mac/Windows)
    src/*.bas             — исходники модулей (версионировать здесь)
    test/golden.py        — эталонные CSV (порт buildCsv/buildMogrtCsv из app.js) для самопроверки
    build/                — сборочные артефакты (тот же dotm)

## Установка

### macOS (Word 2016+)
1. Скопировать `СюжетWord.dotm` в
   `~/Library/Group Containers/UBF8T346G9.Office/User Content.localized/Startup.localized/Word/`
2. Перезапустить Word — макросы доступны во всех документах
   (Сервис → Макрос → Макросы…).

### Windows
1. `Win+R` → `shell:startup` не нужен; папка:
   `%APPDATA%\Microsoft\Word\STARTUP` — положить `СюжетWord.dotm`.
2. Word → Файл → Параметры → Центр управления безопасностью →
   «Проверки при открытии» → доверенные расположение: добавить папку,
   если ставите dotm не в STARTUP.
3. Если после копирования с сетевого диска macOS/Windows блокирует файл
   («безопасность Word»): Свойства файла → Разблокировать.

## Рабочий процесс

1. **Сценарий.** Создать сюжет: `SU_NewStory` (или оформить открытый документ —
   `SU_SetupHere`). Заполнить: `SU_Settings` — название, авторы, FPS, папка
   исходников, папка выгрузки CSV, темп чтеца, план.
2. **Блоки.** `SU_AddBlock` — тип (ЗАГ/ПОДВ/ЗК/СИНХ/СТЕНД/ЛАЙФ/ШПИГ), у СИНХа —
   «Имя Фамилия [Отчество], должность». Заголовки создаются стилями
   «Заголовок 1/2» ровно как в экспорте медиацентра, поэтому «Импорт из Word»
   в Студии такой документ понимает.
3. **Фрагменты.** Вариант А (быстрый): в веб-мониторе Студии разметить In/Out →
   «🐟 В рыбособиратель» → «Загрузить файл…» (скачается fish-CSV) → в Word:
   `SU_FragSync` — выбрать этот CSV, строки `фрагмент | …` расставятся по блокам
   (сопоставление по подписям СИНХn-k/СТЕНДn/ЛАЙФn/ШПИГ и разделам `# ———`).
   Вариант Б: `SU_FragManual` — файл из папки исходников + таймкоды вручную.
4. **Проверка.** `SU_Check` — таймкоды по FPS, in/out, хроно против плана.
   `SU_Renumber` — перенумеровать заголовки после перестановки блоков.
5. **Экспорт.** `SU_Fish` — CSV `;` для Fish Cutter; `SU_Excel` — то же с
   запятой; `SU_Mogrt` — CSV титров; `SU_Clean` — «чистый Word» для редактора
   (без строк «Фрагмент»/«Параметры», копия `_чистый.docx` рядом с документом).
   Файл сохраняется в «папку выгрузки» (из SU_Settings) или рядом с документом.
6. **Premiere.** Fish Cutter → «Загрузить файл…» → собранный макросом CSV
   (формат идентичен экспорту Студии: UTF-8 с BOM, CRLF, `файл; вход; выход;
   подпись; путь`, комментарии `#` с заголовком сюжета и авторами).

Формат служебных строк в документе (стиль «СюжФрагмент», можно править руками):

    фрагмент | A001C003.mov | 00:00:10:00 - 00:00:14:12 | sub/A001C003.mov

и строка «параметры | fps: 25 | темп: 540 | план: 02:30 | исходники: /… | выгрузка: /…».

## Команды (Все макросы: Сервис → Макрос → Макросы…)

    SU_Panel        — меню-панель (InputBox)
    SU_NewStory / SU_SetupHere — новый сюжет / оформить текущий документ
    SU_Settings     — авторы, FPS, папки, темп, план
    SU_AddBlock     — добавить блок текущего типа при курсоре
    SU_FragManual   — фрагмент вручную (файл + in/out)
    SU_FragSync     — синхронизировать фрагменты из fish-CSV Студии
    SU_Check        — проверка сюжета;  SU_Renumber — перенумеровать блоки
    SU_Fish / SU_Excel / SU_Mogrt / SU_Clean — экспорты

## Самопроверка (после установки, ~2 минуты)

Тесты `SU_T_*` работают без открытого документа; финальный `src/70_mTest.bas`
пишет в `<папка шаблона>/test/`. В ПРОКАТИВАНОМ dotm тестовый модуль — старой
dev-версии (пишет в `/Users/Shared/Сюжет-Студия/word/test/`): для самопроверки
на своей машине замените Module3 содержимым `src/70_mTest.bas` (Вставка → Модуль
в редакторе VBA и перенос текста) или пропустите этот раздел. Порядок:
1. Запустить `SU_T_Export` → появятся `su_fish.csv`, `su_fish_excel.csv`,
   `su_mogrt.csv`, `su_check.txt`.
2. `python3 test/golden.py /тудаже` → `golden_fish.csv`, `golden_fish_excel.csv`,
   `golden_mogrt.csv` (эталон — порт buildCsv/buildMogrtCsv из app.js студии).
3. `diff` файлов должен совпадать побайтово (различие допустимо только в строке
   `# … собранный в «Сюжет-Word»`).
4. `SU_T_Sync` — круг «студийный fish-CSV → документ → обратно CSV»: итоговый
   `su_after_sync_fish.csv` равен входному эталону (идемпотентность).

## Известные ограничения / заметки

* **Word for Mac и песочница.** При первой записи/чтении CSV вне контейнера Word
  macOS покажет «Предоставить доступ к файлам» — нужно один раз выбрать папку
  и подтвердить (или дважды кликнуть по строке пути в этом окне). Без этого
  экспорт/синхронизация вернут ошибку выполнения 75.
* В собранном `СюжетWord.dotm` модуль mUI содержит тестовый `AutoExec`
  (запись маркера в контейнер, молча игнорирует ошибки). В `src/60_mUI.bas`
  он уже чистый: при пересборке импортом .bas маркер исчезнет.
* Импорт такого документа обратно в Студию («Импорт из Word») работает, но
  строки «фрагмент | …» попадают как текст блока — для редактора/Студии
  отдавайте «чистый Word» (`SU_Clean`).
* Таймкоды NDF, формат HH:MM:SS:FF; кадры валидируются по round(FPS)
  (29.97 → 30 — как в Студии).
* Горячая клавиша панели на Mac не вешается (VBE-ограничения) — запускайте
  макросы из списка; на Windows можно добавить кнопки на ленту через
  «Настроить ленту» → макросы.

## Пересборка dotm (при изменении src)

Проще всего на Windows: Word → Developer → Visual Basic → импортировать
`src/*.bas` в чистый `СюжетWord.dotm` (Save As → Template with Macros), затем
положить в STARTUP. На Mac редактор VBA не умеет импорт .bas — вставлять тексты
модулей вручную (Сервис → Макрос → Редактор Visual Basic → Insert Module).
