# КОНТЕКСТ ПРОЕКТА — «МЕДИАЦЕНТР» (Сюжет-Студия)

> Бриф для продолжения работы другой нейросетью/разработчиком. Отражает состояние
> на 2026-09-11. Читать вместе с `README.txt`.

## 1. Что это

Веб-приложение для монтажа новостных сюжетов: сценарий с разметкой видео
(таймкоды In/Out), экспорт в Fish Cutter (CSV), Word, MOGRT-титры. Работает
локально: `server.py` раздаёт статику + общий список ФИО (`names.json`),
коллеги в той же сети открывают `http://IP:8765`.

- **Папка:** `/Users/Shared/Сюжет-Студия` (git-репозиторий, ветка не коммитилась).
- **Windows-сборка** перегенерируется: `./make-win.sh` → `../Сюжет-Студия-Windows`
  (bat/README/правки — свои, статика 1:1).
- **Стек:** чистый vanilla JS (без сборки, без npm), Python 3 stdlib сервер,
  один CSS. Файлы: `index.html`, `js/app.js` (движок), `js/octopus.js`
  (оболочка newsroom «МЕДИАЦЕНТР»), `css/style.css`, `server.py`, `names.json`.

## 2. Архитектура и связи (важно для правок)

- `js/app.js` грузится первым, `js/octopus.js` вторым (обычные `<script>`, НЕ
  модули; `"use strict"`). Верхние `const/let` — в lexical-скоупе, НЕ на `window`
  (кроме явно повешенных `window.OC`, `window.SS_HOOK`, `window.SS_IDB_OK`,
  `window.SS_LS_MIGRATED`).
- **Мост между файлами — `SS_HOOK`** (объект точек расширения в app.js:
  `afterRender, afterSave, afterVideoList, beforeSearch, draftMeta, draftLoaded,
  commentCount, showBlockComments`). octopus.js назначает свои функции. РАНЬШЕ
  был опасный monkey-patch (`renderBlocks = function(){...}`) — ЗАМЕНЁН на хуки.
  Новые пересечения функциональности добавляй через `SS_HOOK`, не переназначением.
- Движок самодостаточен без оболочки; оболочка рисует newsroom-слой
  (комментарии/задачи, переключение сюжетов через «Проект» → «Сюжеты…»,
  чек-лист выхода «Утверждение»).

## 3. Модель данных

- **Блок сценария** (`state.blocks`): `{id, kind, text, speaker, role, folded,
  partsFolded, parts:[{file, path, in, out}]}`.
  `kind`: `headline|vod|vo|sync|standup|life|spiegel`. `in/out` — секунды.
  **Ключи `kind` и английские значения `stage` не менять** — на них держатся
  сохранённые данные и триггеры набора. Видимые подписи — отдельно (см. §5).
- **Триггеры нового блока** (DOC_TRIGGERS): на новой строке «хед/лид/зк/синх/
  стенд/лайф/шпи» + пробел.
- **Сюжет** (`OC.stories`): `{id, title, day, time, stage, stageDates, targetSec,
  blocks, nextId, comments, modified}`. `comments`: `{kind, who, text, time,
  done, blockId}` — `blockId` якорит комментарий к блоку.

## 4. Что уже сделано (сессия 2026-09-10)

### P0 — баги и целостность данных
- **Таймкоды для дробных fps (29.97/59.94):** `tc()` теперь считает кадры от
  `Math.round(fps)` (NDF: 30/60 кадров в «секунде» таймкода). Был дрейф ~1с/100с.
- **Фрагменты хранят путь:** добавлен `parts[].path` (relPath). Гашение коллизий
  одноимённых файлов из разных подпапок. `normalizeBlocks` мигрирует старые
  черновики (path←file). В CSV Fish Cutter и MOGRT добавлена колонка «путь».
- **localStorage → IndexedDB:** сюжеты (`oc_stories`, `oc_active`), миниатюры
  (`posters`) и дескриптор папки (`kv`) переехали в IndexedDB (`IDB`-обёртка,
  БД `ss-studio`). При первом запуске — авто-миграция из localStorage с
  освобождением ~5 МБ. Фолбэк: если IDB недоступен (приватный режим) — тихий
  возврат к localStorage.
- **Квота не молчит:** `store.set` при переполнении сам выкидывает легаси-дубли и
  повторяет; если не помогло — баннер `#quotaBanner` с типом ошибки, байтами,
  топ-ключами и кнопками «Сохранить черновик»/«Снимок данных» (диагностический
  JSON с `SS_IDB_OK` и числом сюжетов из IDB). `evict` НЕ трогает `oc_stories`
  пока миграция не подтверждена (`SS_LS_MIGRATED`).
- **Гонки:** `persistStories` буферизуется до конца `ocInit` (проба IDB), чтобы не
  писать мегабайты в localStorage до очистки.
- **Безопасность `names.json`:** CSRF-защита (POST требует `Content-Type:
  application/json` + `X-Requested-With`), версионирование `_v` с `409 Conflict`
  (два пользователя не затирают друг друга), ETag+no-store, HTTP/1.1, блокировка
  `.git/__pycache__/*.bak/*.tmp`. Клиент подтягивает общий список при
  возврате на вкладку (`visibilitychange`).
- **XSS/санитайз:** проверка `meta` импортируемого черновика (`draftLoaded`),
  экранирование в выводах.

## 5. Правила при дальнейшей правке

1. **Не переименовывать** `kind`-ключи, `stage`-значения, `id` элементов, имена
   функций движка — на них завязаны сохранённые данные пользователей и миграции.
2. Русификация — только **видимые** подписи (лейблы option, текст кнопок,
   `KIND_META.badge`, `STAGE_LABEL`).
3. Любое изменение в `js/`/`css/`/`index.html` → потом `./make-win.sh`.
4. Проверка синтаксиса: `node --check js/app.js js/octopus.js`,
   `python3 -m py_compile server.py`.
5. После деплоя — попросить юзера **Cmd+Shift+R** (жёсткая перезагрузка), т.к.
   старые index.html/js могли закэшироваться вразнобой.

## 6. Диагностика / восстановление данных юзера

- «Снимок данных» (кнопка в баннере или `window.OC`+IDB) → `ss-storage-dump.json`
  с `diag.idb.ok`, `diag.stories.count/titles`, фактом миграции.
- Сюжеты реально живут в **IndexedDB** `ss-studio/kv` (ключ `oc_stories`), а не в
  localStorage. localStorage теперь мелкий (`ss_req`, `ss_names_*`, `ss_view`…).
- Черновики юзера: `Проект → Сохранить…` → `.json` (блоки+реквизиты+fps+meta).
